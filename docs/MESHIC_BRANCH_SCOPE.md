# MeshIC Branch Scope

`audit/meshic-data-vet` is intentionally limited to data-integrity and evidence-semantics hardening. It does not attempt a redesign of Lacuna's broader product thesis.

Included: provenance, issuer/entity resolution, arithmetic correctness, metric naming, missingness behavior, validation gates, model-output withholding, and audit documentation.

Excluded for this branch: new investment predictions, new clinical claims, new market-size estimates, or speculative enrichment.
